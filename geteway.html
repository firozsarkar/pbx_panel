⚙️ First Time Setup

Complete this setup to connect the UI with your FreeSWITCH server.

1

Install PHP Backend Script

Copy gateway_api.php to your web directory. This PHP file handles the actual FreeSWITCH commands.

cp gateway_api.php /var/www/html/gateway_api.php chmod 755 /var/www/html/gateway_api.php
2

Give www-data sudo permission

So PHP can write files and run fs_cli commands:

visudo # Add this line: www-data ALL=(ALL) NOPASSWD: /usr/bin/fs_cli, /bin/cp, /bin/rm, /usr/bin/tee
3

Check FreeSWITCH Gateway Directory

Default path: /etc/freeswitch/sip_profiles/external/

ls /etc/freeswitch/sip_profiles/external/ # Should show existing gateway XML files
4

Configure Settings Below

Set your API URL, FreeSWITCH path, and password.

🛠️ Settings & Info

📌 Important Notes:

• This UI writes XML files to FreeSWITCH and reloads via fs_cli
• Gateway XML files are stored in: /etc/freeswitch/sip_profiles/external/
• After adding a gateway, FreeSWITCH automatically tries to register
• Use "Reload" page to check registration status

📁 File locations:
• This file: /var/www/html/gateway.html
• PHP API: /var/www/html/gateway_api.php
